# 任务台账

> 本文件是项目唯一权威任务台账。任务 ID 永久唯一；取消或归档后不得复用。

## 状态定义

## 使用约定

- 新任务按 `TASK-001`、`TASK-002` 顺序分配，禁止重复或复用 ID。
- 前置任务填写 Task ID，多个依赖以逗号分隔；无依赖填写 `—`。
- 任务类型填写 `普通`、`代码`、`里程碑` 或 `代码,里程碑`，用于确定 Commit/Tag 验收要求。
- 新任务创建时记录唯一的 `创建` 事件（原状态填 `—`、新状态填 `TODO`）；每次状态变化追加 `状态变更` 记录，禁止回写或删除历史行。变更时间使用 ISO 8601 格式（如 `2026-11-07T10:05:00`），同一任务的时间不得倒退。
- 从 `DONE` 或 `CANCELLED` 重新打开任务，必须在原因/授权依据中记录原因及明确的用户授权。
- 状态变更遵循本仓库 [{{TASK_GUIDE_FILE}}]({{TASK_GUIDE_FILE}}) 的状态转换规则。
- DONE 任务必须满足验收条件并同步归档到 `plans/done.md`；台账保留索引。
- 代码任务完成后记录真实 Commit SHA；里程碑任务记录真实 Tag。
- 不允许 Agent 自动执行 Git Commit 或 Tag。
