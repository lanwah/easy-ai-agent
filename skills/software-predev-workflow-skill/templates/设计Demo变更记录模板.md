## 规则
- 重要修改必须记录；历史行追加，不覆盖。
- 新增需求、需求语义变化或与已批准设计冲突时，先澄清并按需建立 CR。
- 助手建议不等于用户决定；未经批准不得更新正式基线。
- Git Commit 记录修改过程；重要里程碑使用 Annotated Tag。
