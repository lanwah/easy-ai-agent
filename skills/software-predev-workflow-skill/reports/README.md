# 版本升级报告归档

本目录集中保存 `software-predev-workflow-skill` 技能包各版本的升级过程与验收证据，按目标版本分目录管理。

## 目录规则

```text
reports/
├── README.md
├── V2.2/
│   └── V2.2_升级核对报告.md
├── V2.3/
│   └── V2.3_升级核对报告.md
└── V2.4/
    ├── V2.4_升级核对报告.md
    ├── V2.4_复核报告.md
    └── V2.4_验收测试矩阵.md
```

## 归档约定

1. 每个版本单独建立目录，目录名使用完整版本号（如 `V2.5`）。
2. 文件名使用 `<版本号>_<报告类型>.md`。报告类型包括升级方案、升级核对报告、复核报告、验收测试矩阵；按实际工作需要创建，不强制每版齐全。
3. 历史报告只追加、不覆盖。修订历史报告时，优先新增修订记录或新文件，并说明与原报告的关系。
4. 每次新增/迁移报告后同步更新本索引及技能包根目录 `README.md`（仅当目录说明发生变化时）。
5. 根目录 `CHANGELOG.md` 只维护跨版本变更摘要；`audit-baselines/` 只保存基线快照和对照证据。二者均不迁入本目录。
6. 本目录只管理技能包自身的版本报告，不管理用户软件项目的研发文档。
